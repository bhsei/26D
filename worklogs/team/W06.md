## Decisions
- New use case **UC5 Return Rental**: returning rented equipment happens in a different visit and has its own rules, so the scope grows from 4 to 5 use cases.
- The Customer is a stakeholder, not an actor, because the customer acts only through the cashier.
- Three payment methods are supported: cash, credit card and check (check has priority *Could*).
- All requirement documents are written in English and Markdown under `docs/requirements/`, with one document per commit.
- Requirement IDs follow the conventions document: FR-xx, NFR-xx, BR-xx and IR-xx, with MoSCoW priority.
- All SRS sections use the terms defined in the glossary.
- Reviews are done in GitHub Issues, the same format used for cross-team review.
